# Zcash currency mark

`public/brand/zcash-currency-mark.png` is the original, unmodified standalone Zcash currency icon from the official [Zodl iOS wallet repository](https://github.com/zodl-inc/zodl-ios). It contains the currency-style Z without a surrounding circle or wordmark.

- [Original source asset](https://github.com/zodl-inc/zodl-ios/blob/main/secant/Resources/Assets.xcassets/icons/currencyZec.imageset/currencyZec.png)
- [Source image metadata](https://github.com/zodl-inc/zodl-ios/blob/main/secant/Resources/Assets.xcassets/icons/currencyZec.imageset/Contents.json)
- Retrieved and verified October 8, 2026.
- PNG: 512 × 533 pixels, RGBA, 5,755 bytes.
- Alpha range: 0–255, including 190,644 fully transparent pixels and antialiased edges. No opaque rectangular background.
- Nontransparent bounds: x = 102–397, y = 10–532. Keep this built-in horizontal padding in mind when sizing the displayed mark.
- Main opaque color: RGB (135, 129, 111), `#87816f`.
- Source Git blob: `9a92a9e0505e37addd2dc301df33ed5e1183e779`, checked against the repository tree when downloaded.
- SHA-256: `948c9aeaa9a15c32f51768b5cb70ff4c1bfbd19c3e8ed943e663e6c2c5534e6f`.

The asset was visually checked and its alpha channel inspected. The PNG was copied byte-for-byte; no image generation, background removal, recoloring, or conversion was performed. A CSS alpha mask can display this existing shape in a theme-appropriate foreground while preserving the original asset.

The upstream repository's MIT notice is included at `public/brand/Zodl-MIT-LICENSE.txt`. The name and currency mark identify Zcash; use does not imply endorsement. The [official Zcash media kit](https://z.cash/press/) links its [trademark policy](https://zfnd.org/trademark-policy/).

The official media kit and the [ZecHub brand archive](https://zechub.wiki/zcash-organizations/brand) were also checked. Their PNG icon packs contain surrounding filled or outlined circles, which do not match the requested standalone shape. They are not the source of this asset.
